    How DOM and Data Stay in Sync

    Every task lives inside a JavaScript array that acts as the single source of truth for the app. Whenever you add, complete, or delete a task, that array is updated first, before anything on screen changes. The interface then re-reads the array and rebuilds the visible task list to match it exactly. This one-directional flow — data first, DOM second — keeps what you see and what the app "knows" perfectly in sync.
